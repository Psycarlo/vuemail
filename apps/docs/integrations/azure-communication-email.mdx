## 1. Install dependencies

Get the [vuemail](https://www.npmjs.com/package/vuemail) package and the [Azure Communication Email SDK](https://www.npmjs.com/package/@azure/communication-email).

<CodeGroup>

```sh npm
npm install @azure/communication-email vuemail
```

```sh yarn
yarn add @azure/communication-email vuemail
```

```sh pnpm
pnpm add @azure/communication-email vuemail
```

</CodeGroup>

## 2. Create an email using Vue

Start by building your email template in a `.vue` file.

```vue email.vue
<script setup lang="ts">
import { Button, Html } from 'vuemail';

const { url } = defineProps<{ url: string }>();
</script>

<template>
  <Html lang="en">
    <Button :href="url">Click me</Button>
  </Html>
</template>
```

## 3. Convert to HTML and send email

Import the email template you just built, convert into an HTML string, and use the Azure Communication Email SDK to send it.

```ts
import { EmailClient } from '@azure/communication-email';
import { render } from 'vuemail';
import Email from './email.vue';

const client = new EmailClient(process.env.AZURE_EMAIL_CONNECTION_STRING);

const from ='you@example.com';
const emailHtml = await render(Email, { url: 'https://example.com' });

const message = {
  senderAddress: from,
  content: {
    subject: 'hello world',
    html: emailHtml,
  },
  recipients: {
    to: [{ address: 'user@gmail.com' }],
  },
};

const poller = await client.beginSend(message);

await poller.pollUntilDone();
```

<Info>Azure Communication Email expects the sender in the `senderAddress` field.</Info>
