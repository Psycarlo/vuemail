## 1. Install dependencies

Get the [vuemail](https://www.npmjs.com/package/vuemail), [mailgun.js](https://www.npmjs.com/package/mailgun.js), and [form-data](https://www.npmjs.com/package/form-data) packages.

<CodeGroup>

```sh npm
npm install mailgun.js form-data vuemail
```

```sh yarn
yarn add mailgun.js form-data vuemail
```

```sh pnpm
pnpm add mailgun.js form-data vuemail
```

</CodeGroup>

## 2. Create an email using Vue

Start by building your email template in a `.vue` file.

```vue email.vue
<script setup lang="ts">
import { Button, Html } from 'vuemail';

const { url } = defineProps<{ url: string }>();
</script>

<template>
  <Html lang="en">
    <Button :href="url">Click me</Button>
  </Html>
</template>
```

## 3. Convert to HTML and send email

Import the email template you just built, convert it into an HTML string, and use the Mailgun SDK to send it.

```ts
import { render } from 'vuemail';
import FormData from 'form-data';
import Mailgun from 'mailgun.js';
import Email from './email.vue';

const mailgun = new Mailgun(FormData);
const client = mailgun.client({
  username: 'api',
  key: process.env.MAILGUN_API_KEY,
});

const emailHtml = await render(Email, { url: 'https://example.com' });

await client.messages.create(process.env.MAILGUN_DOMAIN, {
  from: 'you@example.com',
  to: ['user@gmail.com'],
  subject: 'hello world',
  html: emailHtml,
});
```
