## 1. Install dependencies

Get the [vuemail](https://www.npmjs.com/package/vuemail) package and the [Postmark Node.js SDK](https://www.npmjs.com/package/postmark).

<CodeGroup>

```sh npm
npm install postmark vuemail
```

```sh yarn
yarn add postmark vuemail
```

```sh pnpm
pnpm add postmark vuemail
```

</CodeGroup>

## 2. Create an email using Vue

Start by building your email template in a `.vue` file.

```vue email.vue
<script setup lang="ts">
import { Button, Html } from 'vuemail';

const { url } = defineProps<{ url: string }>();
</script>

<template>
  <Html lang="en">
    <Button :href="url">Click me</Button>
  </Html>
</template>
```

## 3. Convert to HTML and send email

Import the email template you just built, convert into an HTML string, and use the Postmark SDK to send it.

```ts
import { render } from 'vuemail';
import postmark from 'postmark';
import Email from './email.vue';

const client = new postmark.ServerClient(process.env.POSTMARK_API_KEY);

const emailHtml = await render(Email, { url: 'https://example.com' });

const options = {
  From: 'you@example.com',
  To: 'user@gmail.com',
  Subject: 'hello world',
  HtmlBody: emailHtml,
};

await client.sendEmail(options);
```
