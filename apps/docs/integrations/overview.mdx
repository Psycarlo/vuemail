In order to use Vuemail with any email service provider, you'll need to convert the components made with Vue into a HTML string. This is done using the [render](/utilities/render) utility.

Since emails are `.vue` files, the code that imports them to render them needs to compile single file components. On Node.js,
that means running it through a bundler with a Vue plugin, like [Nuxt](/getting-started/nuxt) with the `@vuemaildev/nuxt` module,
Vite, or tsdown with `unplugin-vue`. See [compiling emails](/guides/vite) for how to set each one up.
