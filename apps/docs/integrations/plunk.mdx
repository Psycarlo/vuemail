## 1. Install dependencies

Get the [vuemail](https://www.npmjs.com/package/vuemail) package and the [Plunk Node.js SDK](https://www.npmjs.com/package/@plunk/node).

<CodeGroup>

```sh npm
npm install @plunk/node vuemail
```

```sh yarn
yarn add @plunk/node vuemail
```

```sh pnpm
pnpm add @plunk/node vuemail
```

</CodeGroup>

## 2. Create an email using Vue

Start by building your email template in a `.vue` file.

```vue email.vue
<script setup lang="ts">
import { Button, Html } from 'vuemail';

const { url } = defineProps<{ url: string }>();
</script>

<template>
  <Html lang="en">
    <Button :href="url">Click me</Button>
  </Html>
</template>
```

## 3. Convert to HTML and send email

Import the email template you just built, convert into an HTML string, and use the Plunk SDK to send it.

```ts
import Plunk from "@plunk/node";
import { render } from 'vuemail';
import Email from './email.vue';

const plunk = new Plunk(process.env.PLUNK_API_KEY);

const emailHtml = await render(Email, { url: 'https://example.com' });

plunk.emails.send({
  to: "hello@useplunk.com",
  subject: "Hello world",
  body: emailHtml,
});
```
