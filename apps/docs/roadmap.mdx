If any of these are important to you please let us know. We use community feedback to plan our roadmap, and we also encourage contributors to submit their ideas on [GitHub Discussions](https://github.com/vuemail/vuemail/discussions) so that we can discuss them with the community.

Feel free to contribute to any of them as well.

## Planned Features

These are the features that we've planned to work on in the near future.

### Keeping in sync with React Email

Vuemail is a 1:1 port of [React Email](https://react.email). New components, fixes and features released upstream get ported to Vuemail, so that both keep the same APIs and render the same HTML.

### VS Code extension

Build a VS Code extension where developers can build the email using Vue on one side and see a live preview right next to it.
