## Update the packages

`@vuemaildev/vuemail` and `@vuemaildev/ui` are released together, and the CLI only runs the preview app when both
are in the same version, so always update them at once:

<CodeGroup>

```sh npm
npm install @vuemaildev/vuemail@latest
npm install @vuemaildev/ui@latest -D
```

```sh yarn
yarn add @vuemaildev/vuemail@latest
yarn add @vuemaildev/ui@latest -D
```

```sh pnpm
pnpm add @vuemaildev/vuemail@latest
pnpm add @vuemaildev/ui@latest -D
```

```sh bun
bun add @vuemaildev/vuemail@latest
bun add @vuemaildev/ui@latest -D
```

</CodeGroup>

If you use them, update `@vuemaildev/nuxt`, `@vuemaildev/editor` and `@vuemaildev/render` too.

<Info>
  `@vuemaildev/vuemail` includes everything in `@vuemaildev/render`, so you only need `@vuemaildev/render` when you want
  the render utility on its own. The editor, `@vuemaildev/editor`, and the preview app, `@vuemaildev/ui`,
  are separate packages.
</Info>
