## Install

Install component from your command line.

<CodeGroup>

```sh npm
npm install vuemail -E
```

```sh yarn
yarn add vuemail -E
```

```sh pnpm
pnpm add vuemail -E
```

</CodeGroup>

## Getting started

Add the component to your email template. Include styles where needed.

```vue
<script setup lang="ts">
import { Column, Row, Section } from 'vuemail';
</script>

<template>
  <Section>
    <Row>
      <Column>A</Column>
    </Row>
    <Row>
      <Column>B</Column>
    </Row>
    <Row>
      <Column>C</Column>
    </Row>
  </Section>
</template>
```
