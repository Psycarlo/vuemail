## Install

Install component from your command line.

<CodeGroup>

```sh npm
npm install vuemail -E
```

```sh yarn
yarn add vuemail -E
```

```sh pnpm
pnpm add vuemail -E
```

</CodeGroup>

## Getting started

Add the component to your email template. Include styles where needed.

```vue
<script setup lang="ts">
import { Text } from 'vuemail';
</script>

<template>
  <Text>Lorem ipsum</Text>
</template>
```
