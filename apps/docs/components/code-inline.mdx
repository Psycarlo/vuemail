## Install

Install the component from your command line.

<CodeGroup>

```sh npm
npm install vuemail -E
```

```sh yarn
yarn add vuemail -E
```

```sh pnpm
pnpm add vuemail -E
```

</CodeGroup>

## Getting Started

Add the component to your email template. Include styles where needed.

```vue
<script setup lang="ts">
import { CodeInline } from 'vuemail';
</script>

<template>
  <CodeInline>npm install vuemail</CodeInline>
</template>
```
