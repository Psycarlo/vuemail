# Internationalization (i18n) Guide

Complete guide for implementing multi-language email support with Vuemail using Tailwind CSS styling.

## Table of Contents

- [vue-i18n](#vue-i18n)
- [Messages as Props](#messages-as-props)
- [Message File Organization](#message-file-organization)
- [Best Practices](#best-practices)
- [Example: Complete Multi-locale Email](#example-complete-multi-locale-email)

Vuemail supports two approaches: vue-i18n, installed on the Vue app that renders the email through the `setupApp` option of `render`, and plain messages passed as props.

## vue-i18n

Best choice for Vue and Nuxt applications, and for complex formatting needs (plurals, dates, numbers).

### Installation

```bash
npm install vue-i18n
```

### Setup

**1. Create message files:**

```json
// messages/en.json
{
  "welcome-email": {
    "subject": "Welcome to Acme",
    "greeting": "Hi",
    "body": "Thanks for signing up! We're excited to have you on board.",
    "cta": "Get Started",
    "footer": "If you have questions, reply to this email."
  }
}
```

```json
// messages/es.json
{
  "welcome-email": {
    "subject": "Bienvenido a Acme",
    "greeting": "Hola",
    "body": "¡Gracias por registrarte! Estamos emocionados de tenerte en la plataforma.",
    "cta": "Comenzar",
    "footer": "Si tienes preguntas, responde a este correo electrónico."
  }
}
```

```json
// messages/fr.json
{
  "welcome-email": {
    "subject": "Bienvenue chez Acme",
    "greeting": "Bonjour",
    "body": "Merci de vous être inscrit ! Nous sommes ravis de vous accueillir.",
    "cta": "Commencer",
    "footer": "Si vous avez des questions, répondez à cet e-mail."
  }
}
```

In vue-i18n messages, `{`, `}`, `@` and `|` are syntax (interpolations, linked messages, plurals). Write them as literals, like `support{'@'}acme.com`, when a message needs them.

**2. Create the i18n instance:**

```ts
// emails/i18n.ts
import { createI18n, useI18n } from 'vue-i18n';
import en from '../messages/en.json';
import es from '../messages/es.json';
import fr from '../messages/fr.json';

export function createEmailI18n(locale: string) {
  return createI18n({
    legacy: false,
    locale,
    fallbackLocale: 'en',
    messages: { en, es, fr },
  });
}

type EmailComposer = ReturnType<typeof createEmailI18n>['global'];

/**
 * `useI18n()` for emails: rendered with the instance installed through
 * `setupApp`, it's that instance. The preview renders emails without
 * `setupApp`, so there it falls back to an instance for the given locale.
 */
export function useEmailI18n(locale: string): EmailComposer {
  try {
    return useI18n() as EmailComposer;
  } catch {
    return createEmailI18n(locale).global;
  }
}
```

Create an instance for each render instead of sharing one and switching its locale: a server renders emails for different locales at the same time.

**3. Update email template:**

```vue
<!-- emails/welcome.vue -->
<script setup lang="ts">
import {
  Body,
  Button,
  Container,
  Head,
  Heading,
  Hr,
  Html,
  Preview,
  Tailwind,
  Text,
  pixelBasedPreset,
} from 'vuemail';
import { useEmailI18n } from './i18n';

interface WelcomeEmailProps {
  name: string;
  verificationUrl: string;
  locale: string;
}

const { name, verificationUrl, locale } = defineProps<WelcomeEmailProps>();

// Preview props
defineOptions({
  PreviewProps: {
    name: 'John',
    verificationUrl: 'https://example.com/verify',
    locale: 'en',
  } satisfies WelcomeEmailProps,
});

const { t } = useEmailI18n(locale);
</script>

<template>
  <Html :lang="locale">
    <Tailwind :config="{ presets: [pixelBasedPreset] }">
      <Head />
      <Body class="bg-gray-100 font-sans">
        <Preview>{{ t('welcome-email.subject') }}</Preview>
        <Container class="mx-auto py-10 px-5 max-w-xl">
          <Heading class="text-2xl font-bold text-gray-800">
            {{ t('welcome-email.subject') }}
          </Heading>
          <Text class="text-base leading-7 text-gray-800 my-4">
            {{ t('welcome-email.greeting') }} {{ name }},
          </Text>
          <Text class="text-base leading-7 text-gray-800 my-4">
            {{ t('welcome-email.body') }}
          </Text>
          <Button
            :href="verificationUrl"
            class="bg-blue-600 text-white px-5 py-3 rounded block text-center no-underline box-border"
          >
            {{ t('welcome-email.cta') }}
          </Button>
          <Hr class="border-solid border-gray-200 my-5" />
          <Text class="text-sm text-gray-500">
            {{ t('welcome-email.footer') }}
          </Text>
        </Container>
      </Body>
    </Tailwind>
  </Html>
</template>
```

Components that the email renders can call `useI18n()` directly, as long as the email is rendered with `setupApp`.

**4. Send with locale:**

Install the instance for the recipient's locale with `setupApp`, which `render` calls with the Vue app before rendering:

```ts
import { Resend } from 'resend';
import type { App } from 'vue';
import { render } from 'vuemail';
import { createEmailI18n } from './emails/i18n';
import WelcomeEmail from './emails/welcome.vue';

const resend = new Resend(process.env.RESEND_API_KEY);

const locale = 'fr';
const i18n = createEmailI18n(locale);
const setupApp = (app: App) => app.use(i18n);
const props = { name: 'Jean', verificationUrl: 'https://example.com/verify', locale };

await resend.emails.send({
  from: 'Acme <onboarding@resend.dev>',
  to: ['user@example.com'],
  subject: i18n.global.t('welcome-email.subject'),
  html: await render(WelcomeEmail, props, { setupApp }),
  text: await render(WelcomeEmail, props, { setupApp, plainText: true }),
});
```

### Plurals, Dates, and Numbers

vue-i18n separates plural forms with `|`, and passes the count as `{count}` (or `{n}`):

```json
// messages/en.json
{
  "welcome-email": {
    "item-count": "no items | {count} item | {count} items"
  }
}
```

```vue
<Text class="text-base text-gray-800">
  {{ t('welcome-email.item-count', itemCount) }}
</Text>
```

For dates and numbers, use `Intl` with the email's locale, or configure `datetimeFormats` and `numberFormats` in `createI18n` and use `d()` and `n()`, which the composer returns next to `t()`.

## Messages as Props

The minimal approach, without a library: load the messages for the locale where you render the email, and pass them as a prop. It works in the preview through `PreviewProps`, which can use imported values.

**1. Use the messages in the email:**

```vue
<!-- emails/welcome.vue -->
<script setup lang="ts">
import {
  Body,
  Button,
  Container,
  Heading,
  Html,
  Tailwind,
  Text,
  pixelBasedPreset,
} from 'vuemail';
import en from '../messages/en.json';

interface WelcomeEmailMessages {
  subject: string;
  greeting: string;
  body: string;
  cta: string;
  footer: string;
}

interface WelcomeEmailProps {
  name: string;
  locale: string;
  messages: WelcomeEmailMessages;
}

const { name, locale, messages } = defineProps<WelcomeEmailProps>();

defineOptions({
  PreviewProps: {
    name: 'John',
    locale: 'en',
    messages: en['welcome-email'],
  } satisfies WelcomeEmailProps,
});
</script>

<template>
  <Html :lang="locale">
    <Tailwind :config="{ presets: [pixelBasedPreset] }">
      <Body class="bg-gray-100 font-sans">
        <Container class="mx-auto p-5 max-w-xl">
          <Heading class="text-2xl font-bold text-gray-800">
            {{ messages.subject }}
          </Heading>
          <Text class="text-base text-gray-800">
            {{ messages.greeting }} {{ name }},
          </Text>
          <Text class="text-base text-gray-800">
            {{ messages.body }}
          </Text>
          <Button
            href="https://example.com"
            class="bg-blue-600 text-white px-5 py-3 rounded box-border"
          >
            {{ messages.cta }}
          </Button>
        </Container>
      </Body>
    </Tailwind>
  </Html>
</template>
```

**2. Pass the messages of the locale when rendering:**

```ts
import { render } from 'vuemail';
import WelcomeEmail from './emails/welcome.vue';
import en from './messages/en.json';
import es from './messages/es.json';
import fr from './messages/fr.json';

const messagesByLocale: Record<string, typeof en> = { en, es, fr };

const locale: string = 'es';
const messages = messagesByLocale[locale] ?? en;

const html = await render(WelcomeEmail, {
  name: 'Ana',
  locale,
  messages: messages['welcome-email'],
});
```

## Message File Organization

### By Namespace (Recommended)

Organize translations by email template:

```
messages/
├── en.json          # All English translations
│   ├── welcome-email
│   ├── password-reset
│   └── order-confirmation
├── es.json          # All Spanish translations
└── fr.json          # All French translations
```

Or organize by template with separate files:

```
messages/
├── en/
│   ├── welcome-email.json
│   ├── password-reset.json
│   └── order-confirmation.json
├── es/
│   ├── welcome-email.json
│   ├── password-reset.json
│   └── order-confirmation.json
└── fr/
    ├── welcome-email.json
    ├── password-reset.json
    └── order-confirmation.json
```

With separate files, combine them per locale in `createI18n`, like `messages: { en: { 'welcome-email': enWelcomeEmail } }`.

### Translation Keys

Use descriptive, hierarchical keys:

```json
{
  "welcome-email": {
    "subject": "Welcome!",
    "preview": "Get started with your account",
    "header": {
      "title": "Welcome to Acme",
      "subtitle": "We're glad you're here"
    },
    "body": {
      "greeting": "Hi",
      "intro": "Thanks for signing up!",
      "next-steps": "Here's how to get started:"
    },
    "cta": {
      "primary": "Get Started",
      "secondary": "Learn More"
    },
    "footer": {
      "help": "Need help? Reply to this email",
      "unsubscribe": "Unsubscribe from these emails"
    }
  }
}
```

## Best Practices

### 1. Always Pass Locale

Make locale a required prop:

```ts
interface EmailProps {
  locale: string;
  // other props...
}
```

### 2. Set HTML Lang Attribute

```vue
<Html :lang="locale">
  <!-- email content -->
</Html>
```

### 3. Support RTL Languages

For Arabic, Hebrew, etc.:

```vue
<script setup lang="ts">
import { Html } from 'vuemail';

const { locale } = defineProps<{ locale: string }>();

const isRTL = ['ar', 'he', 'fa'].includes(locale);
</script>

<template>
  <Html :lang="locale" :dir="isRTL ? 'rtl' : 'ltr'">
    <!-- email content -->
  </Html>
</template>
```

### 4. Fallback Values

Provide fallback translations with `fallbackLocale`, used for the messages missing in the locale:

```ts
createI18n({
  legacy: false,
  locale,
  fallbackLocale: 'en',
  messages: { en, es, fr },
});
```

### 5. Test All Locales

Test email rendering for each supported locale:

```ts
defineOptions({
  PreviewProps: {
    name: 'Test User',
    locale: 'en', // Change to test different locales
  },
});
```

### 6. Keep Keys Consistent

Use the same translation keys across all locale files:

```json
// ✅ Good
// en.json: { "cta": "Get Started" }
// es.json: { "cta": "Comenzar" }

// ❌ Bad
// en.json: { "button": "Get Started" }
// es.json: { "cta": "Comenzar" }
```

### 7. Handle Missing Translations

Set up fallback behavior:

```ts
createI18n({
  legacy: false,
  locale,
  fallbackLocale: 'en',
  messages,
  missing: (locale, key) => {
    console.warn(`Translation missing: ${key} (${locale})`);
  },
});
```

### 8. Subject Line Translation

Don't forget to translate email subjects:

```ts
const i18n = createEmailI18n(locale);

await resend.emails.send({
  from: 'Acme <onboarding@resend.dev>',
  to: [user.email],
  subject: i18n.global.t('welcome-email.subject'), // ✅ Translated subject
  html: await render(WelcomeEmail, props, { setupApp: (app) => app.use(i18n) }),
});
```

### 9. Format Consistency

Maintain consistent formatting across locales:
- Date formats (MM/DD/YYYY vs DD/MM/YYYY)
- Time formats (12h vs 24h)
- Number separators (1,234.56 vs 1.234,56)
- Currency symbols and placement ($100 vs 100$)

Use `Intl` APIs for automatic locale-specific formatting.

## Example: Complete Multi-locale Email

```vue
<script setup lang="ts">
import {
  Body,
  Button,
  Container,
  Head,
  Heading,
  Hr,
  Html,
  Preview,
  Section,
  Tailwind,
  Text,
  pixelBasedPreset,
} from 'vuemail';
import { useEmailI18n } from './i18n';

interface OrderConfirmationProps {
  orderNumber: string;
  total: number;
  currency: string;
  locale: string;
  orderDate: Date;
}

const { orderNumber, total, currency, locale, orderDate } =
  defineProps<OrderConfirmationProps>();

defineOptions({
  PreviewProps: {
    orderNumber: '10234',
    total: 883.4,
    currency: 'USD',
    locale: 'en',
    orderDate: new Date(),
  } satisfies OrderConfirmationProps,
});

const { t } = useEmailI18n(locale);

const isRTL = ['ar', 'he'].includes(locale);

const currencyFormatter = new Intl.NumberFormat(locale, {
  style: 'currency',
  currency,
});

const dateFormatter = new Intl.DateTimeFormat(locale, {
  year: 'numeric',
  month: 'long',
  day: 'numeric',
});
</script>

<template>
  <Html :lang="locale" :dir="isRTL ? 'rtl' : 'ltr'">
    <Tailwind :config="{ presets: [pixelBasedPreset] }">
      <Head />
      <Body class="bg-gray-100 font-sans">
        <Preview>{{ t('order-confirmation.preview') }}</Preview>
        <Container class="mx-auto py-10 px-5 max-w-xl">
          <Heading class="text-2xl font-bold text-gray-800">
            {{ t('order-confirmation.title') }}
          </Heading>
          <Text class="text-base text-gray-800 my-2">
            {{ t('order-confirmation.order-number') }}: {{ orderNumber }}
          </Text>
          <Text class="text-base text-gray-800 my-2">
            {{ t('order-confirmation.order-date') }}: {{ dateFormatter.format(new Date(orderDate)) }}
          </Text>
          <Section class="bg-white p-5 rounded my-4">
            <Text class="text-xl font-bold text-gray-800">
              {{ t('order-confirmation.total') }}: {{ currencyFormatter.format(total) }}
            </Text>
          </Section>
          <Button
            :href="`https://example.com/orders/${orderNumber}`"
            class="bg-blue-600 text-white px-5 py-3 rounded block text-center no-underline my-5 box-border"
          >
            {{ t('order-confirmation.view-order') }}
          </Button>
          <Hr class="border-solid border-gray-200 my-5" />
          <Text class="text-sm text-gray-500">
            {{ t('order-confirmation.footer') }}
          </Text>
        </Container>
      </Body>
    </Tailwind>
  </Html>
</template>
```

With message files:

```json
// messages/en.json
{
  "order-confirmation": {
    "preview": "Your order has been confirmed",
    "title": "Order Confirmed",
    "order-number": "Order number",
    "order-date": "Order date",
    "total": "Total",
    "view-order": "View Order",
    "footer": "Thank you for your purchase!"
  }
}
```

```json
// messages/es.json
{
  "order-confirmation": {
    "preview": "Tu pedido ha sido confirmado",
    "title": "Pedido Confirmado",
    "order-number": "Número de pedido",
    "order-date": "Fecha del pedido",
    "total": "Total",
    "view-order": "Ver Pedido",
    "footer": "¡Gracias por tu compra!"
  }
}
```
